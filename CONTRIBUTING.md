# Contributing

Use Node 22.23.2 and install from the npm lockfile with npm ci. Run npm test and npm run build before submitting changes. For browser behavior, install the Playwright browsers and run npm run test:e2e against the built site.

A numerical issue should have a small synthetic reproduction with the join kinds, owner and expected source identities. Keep fixtures free of data from real reports. Compare changes in reconciliation semantics with the independent SQLite oracle. Check keyboard operation and a narrow viewport for interface changes.
